# LLM Extraction

Ein Lernprojekt zur KI-gestützten Verarbeitung von Fallberichten.

## Projekt

Das Programm verarbeitet einen realistischen Fallbericht mit wichtigen
und unwichtigen Informationen über einen Klienten und nutzt eine
LLM-API, um daraus relevante Betreuungsbedarfe und Aufgaben für
Sozialarbeiter im ambulant unterstützten Wohnen zu extrahieren.

Die extrahierten Daten werden als JSON verarbeitet und anschließend
in einer SQLite-Datenbank gespeichert.

## Technologien

- C#
- Google Gemini API: 3.1 Flash-Lite
- SQLite
- JSON
